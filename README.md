# Student Result Analysis using Python

## Project Overview

This project analyzes student marks using Python, Pandas, and Matplotlib.

The program calculates:
- Total marks
- Average marks
- Pass/Fail result
- Subject-wise average marks
- Student average marks visualization

## Technologies Used

- Python
- Pandas
- Matplotlib

## Dataset

The project uses student marks data for:
- Maths
- Python
- DBMS

## Features

1. Calculate total marks of each student.
2. Calculate average marks.
3. Determine Pass/Fail status.
4. Display average marks of subjects.
5. Create a bar chart of student average marks.

## Project Files

- `student_result.py` - Main Python program
- `students.csv` - Student dataset
- `README.md` - Project documentation
